This assistant is a local, deterministic search layer over Hanan's portfolio. It runs
entirely in the browser — there is no external AI API behind it, no server, and no
request ever leaves the page.

It answers by matching a question against a small set of curated knowledge files
written from Hanan's résumés, then returning the relevant passage. That design means
it can only tell you things that are actually in his portfolio — it cannot invent an
employer, a metric, or a project.

If it doesn't know something, it will say so rather than guess.

The site itself is built with Next.js, TypeScript, and Tailwind CSS, and deploys as a
fully static site.
