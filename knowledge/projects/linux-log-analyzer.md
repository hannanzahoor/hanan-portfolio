**Intelligent Linux Log Analyzer — ML-Driven Security Monitoring System** (April 2026)
Category: Machine Learning · Full Stack · Security
Repository: https://github.com/hannanzahoor/log-analyzer

A Linux security monitoring system that combines a machine learning detection pipeline
with real-time log ingestion and a live web dashboard.

What Hanan built:
- A Linux log analyzer using Python, Flask, React, and MongoDB for real-time
  monitoring and debugging.
- An ML pipeline using TF-IDF, LSA, and ensemble learning to classify known attacks
  and detect anomalous system behavior.
- Flask REST APIs and a real-time dashboard for log ingestion, visualization, model
  inference, and security alert management.

Technologies: Python, Flask, React, MongoDB, TF-IDF, LSA, Ensemble Learning, REST APIs.

Concepts demonstrated: machine learning pipeline, text classification, anomaly
detection, log ingestion, REST APIs, real-time dashboard, security monitoring.

This is the project that most directly bridges his AI/ML and software engineering
work — it is simultaneously an ML system and a full-stack application.
