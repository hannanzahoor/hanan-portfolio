**Privora — Privacy-First Social Platform** (July 2025)
Category: Full Stack · Security
Repository: https://github.com/hannanzahoor/Privora---Decentralized-P2P-Social-Platform

A privacy-first social platform built around end-to-end encrypted messaging,
encrypted file sharing, and QR-based key exchange.

What Hanan built:
- A privacy-first social platform using React, TypeScript, Express.js, and SQLite
  with secure real-time communication.
- AES-GCM encryption and PBKDF2 key derivation for end-to-end encrypted messaging.
- Disappearing messages, encrypted file sharing, QR-based key exchange, and secure
  REST APIs.

Technologies: React, TypeScript, Express.js, SQLite, AES-GCM, PBKDF2, REST APIs.

Concepts demonstrated: full-stack development, encryption, secure communication,
key exchange, backend APIs, privacy-focused product design.
