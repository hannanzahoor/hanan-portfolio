**AirSense AI — LLM-Powered AQI & Health Advisor** (July 2026)
Category: AI/ML · Generative AI
Repository: https://github.com/hannanzahoor/airsense-ai

An LLM-powered air quality advisor that pairs live environmental data with an agentic
workflow to produce personalized, context-aware health recommendations.

What Hanan built:
- An LLM-powered AQI advisor using Python, GPT-4o, Agno, Firecrawl, and Gradio.
- An agentic workflow using prompt engineering techniques to retrieve live AQI data
  and generate personalized recommendations from structured and unstructured sources.
- GPT-4o API integration producing context-aware health recommendations from AQI,
  weather, medical history, and user activity — with response quality improved
  through iterative prompt refinement and evaluation.
- Live REST API integration with validation and error handling to improve
  recommendation reliability.

Technologies: Python, GPT-4o, Agno, Firecrawl, Gradio, Prompt Engineering, LLM APIs.

Concepts demonstrated: LLM applications, AI agents, live data retrieval, structured
and unstructured data, prompt engineering, model evaluation.
